The Problem & The Approach

The problem

The Bureau needed one place to manage its training and reference video content for trustees, instead of files and links spread across drives and message threads — and no website for the Bureau itself.

The approach

Build both as one MERN application: a website for the Bureau, and a dedicated video management portal where trustees can upload, organize and retrieve training content from a single internal system.

What We Built

One platform, two parts.

Bureau Website

A web presence for the Bureau, built and delivered as part of the same engagement.

Learning Video Portal

A dedicated system for uploading, organizing and retrieving the Bureau's training video content in one place.

Built for Trustees

An internal system for the Bureau's trustees, not a public-facing product — access is restricted by design.

MERN Stack

MongoDB for data, Express and Node.js for the API layer, React for the interface — one JavaScript stack end to end.
